# Contributing to CIFAR-10 Image Recognition System

Thank you for your interest in contributing to this project!

## Development Setup

1. Clone the repository
2. Create a virtual environment
3. Install dependencies: `pip install -r requirements.txt`
4. Run tests: `pytest`

## Code Standards

- Follow PEP 8 style guide
- Use Black for code formatting (`black .`)
- Use Ruff for linting (`ruff check .`)
- Write docstrings for all functions and classes
- Add type hints where applicable
- Maintain test coverage above 80%

## Git Workflow

- Work on the `develop` branch for features
- Create feature branches: `feature/your-feature-name`
- Commit messages follow conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`
- Merge to `main` only for releases

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure all tests pass
4. Update CHANGELOG.md
5. Request review from project maintainers

## Questions?

Contact the project team members listed in README.md

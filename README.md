## 📋 Project Overview

An advanced image recognition system built using Convolutional Neural Networks (CNN) to classify images from the CIFAR-10 dataset into 10 distinct categories.

## 🎯 Features

- ✅ CNN-based image classification (10 classes)
- ✅ RESTful API with FastAPI
- ✅ Web-based UI for image upload and prediction
- ✅ Docker containerization
- ✅ Automated CI/CD with GitHub Actions
- ✅ Production-ready deployment on Render
